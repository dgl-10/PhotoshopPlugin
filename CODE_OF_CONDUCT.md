# Code of Conduct

## Our standard

Be respectful, constructive, and specific. This project welcomes artists, retouchers, developers, and first-time contributors with different levels of Photoshop, JavaScript, and AI-tool experience.

Examples of positive participation include:

- focusing feedback on the workflow or code rather than the person;
- sharing reproducible details without exposing private artwork or credentials;
- accepting that different artists use different providers, tools, and platforms;
- giving contributors time to respond and revise their work.

Harassment, personal attacks, discrimination, threats, sexualized content directed at participants, deliberate disclosure of private information, and repeated disruptive behavior are not acceptable.

## Scope and enforcement

This code applies to repository issues, pull requests, discussions, release comments, and other project spaces. Maintainers may edit or remove content, lock conversations, reject contributions, or restrict participation when necessary.

For a sensitive conduct report, contact the maintainer through the [dgl-10 GitHub profile](https://github.com/dgl-10) rather than posting personal details publicly. Reports will be reviewed as privately and promptly as practical.
