# 🎬 Video Scenario: "FromPS / ToPS — 90-Second Demo"

> **Goal**: Show the complete workflow from selection to seamless result in under 90 seconds.
> **Tone**: Energetic, professional, impressive. No narration needed if text overlays are used.
> **Music**: Upbeat, modern electronic / lo-fi — something creative and inspiring.

---

### 🎬 Scene 1 — The Hook (0:00–0:10)

**Visual**: Quick montage of 3-4 dramatic before/after pairs (zoom transitions).
**Text overlay**: *"What if you could use ANY AI inside Photoshop?"*
**Text overlay**: *"No API lock-in. No per-image fees. Just results."*

---

### 🎬 Scene 2 — The Problem (0:10–0:20)

**Visual**: Speed-up footage of the painful manual workflow:
- Screenshotting, cropping in Paint, saving file
- Opening browser, uploading, waiting
- Downloading result, placing it manually, resizing, trying to align
- Frustrated face / error messages / misaligned edges

**Text overlay**: *"The old way? Copy, crop, upload, download, resize, align, mask... again and again."*

---

### 🎬 Scene 3 — The Plugin in Action: Browser Path (0:20–0:45)

**Visual**: Smooth screen recording in Photoshop:
1. **(0:20)** Photoshop canvas with a photo. User selects an area with the Lasso tool (irregular shape around a jacket).
2. **(0:25)** Clicks **"Capture Selection"** in the FromPS panel → preview and mask appear instantly.
3. **(0:28)** Clicks **"Drag Out"** → a small floating drag window appears under the cursor.
4. **(0:30)** User drags the files into a browser tab (e.g., ChatGPT image editor). AI generates the result.
5. **(0:38)** User copies the result. Back in Photoshop — clicks **"Paste"** then **"Place Back"**.
6. **(0:42)** The result snaps into place perfectly. Show the layers panel: Smart Object + Mask + Blur.

**Text overlays at key moments**:
- *"Select → Capture → Drag to any AI"*
- *"One click back — pixel-perfect placement"*

---

### 🎬 Scene 4 — The Plugin in Action: WebHelper Path (0:45–1:10)

**Visual**: Continue the screen recording:
1. **(0:45)** New selection in Photoshop. User clicks **"Send to WebHelper"**.
2. **(0:48)** Cut to browser — WebHelper automatically shows the new task with source image and mask overlay.
3. **(0:52)** User selects an AI model from dropdown (e.g., "Grok Imagine"), types a prompt, clicks **"Generate"**.
4. **(0:56)** Loading spinners → 3 results appear as tabs. User browses them.
5. **(1:02)** User clicks **"Copy to Clipboard"** on the best result.
6. **(1:04)** Back in Photoshop → **Paste** → **Place Back** → seamless integration.
7. **(1:08)** Quick zoom into edges — seamless blend, no visible seams.

**Text overlays**:
- *"Built-in WebHelper — generate through Grok, FLUX, Seedream, and more"*
- *"Compare results. Pick the best. Place back in one click."*

---

- Show 2-3 impressive examples in quick succession.
- Final shot: Photoshop layers panel showing the clean, non-destructive result structure.

**Text overlay**: *"Smart Object. Layer Mask. Gaussian Blur. Non-destructive. Ctrl+Z to undo."*
