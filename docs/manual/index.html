FromPS / ToPS documentation

Capture. Send out. Place back.

This guide explains every control in the Photoshop panel and the shortest complete workflow. Keep it open beside Photoshop, or use it offline from the installed application folder.

→
FromPS Photoshop to an AI tool
←
ToPS Generated image back to Photoshop

On this page

01 Quick start 02 Panel map 03 Capture controls 04 Send image & mask 05 Place back 06 Feather bias 07 History & settings 08 Troubleshooting

Requires Adobe Photoshop 2024 or newer and the FromPS / ToPS panel open.

01

The complete loop

Quick start

For most jobs, these are the only four steps you need.

1

Select and capture

Make a selection in Photoshop. In FromPS, leave PsSource on Copy merged for the visible composite, then click Capture Selection.

2

Send the capture out

Export via Drag*, Copy Image*, Copy Mask*, or Save as PNG. FromPS calculates and displays the exact aspect ratio (e.g., [3:4]) alongside pixel dimensions — set the matching ratio preset in your AI generator to prevent image stretching and distortion.

3

Load the generated image

In ToPS, use Load File… or Paste* to add the generated image to the panel.

4

Place it back in Photoshop

Confirm the correct history item is selected, then click Place Back.

!

Before Place Back: choose the history entry that belongs to the result. That entry stores the coordinates and mask used for placement.

03

FromPS card

Capture controls

Choose what Photoshop should copy, then choose how accurately it should be extracted.

PsSource

Copy merged default
Captures the combined appearance of all visible layers inside the selection.
Copy layer
Captures only the currently active Photoshop layer.

Capture Selection

Main button
Captures the current selection with the currently chosen mode.
Fast default
Quick bounding-box capture for opaque work where preserved transparency is not required.
Slow with transparency
Uses a temporary document to preserve transparent pixels and soft selection edges.
Full Doc Mask — Fast
Creates a mask at the full document size without transparency processing.
Full Doc Mask — Slow
Creates a full-canvas mask while preserving transparency.
i

Rule of thumb: start with Fast. Use a Slow mode when soft or transparent edges matter.

04

FromPS toolbar

Send the image and mask

Pick the transport that best matches the external AI application.

Save as PNG

Main button
Saves using the currently selected save option.
Image Only
Saves the color image.
Mask Only
Saves the black-and-white selection mask.
Both
Saves image and mask as separate PNG files.

Clipboard buttons

Copy Image*
Copies the captured color image to the system clipboard.
Copy Mask*
Copies the selection mask to the system clipboard.

Drag*

Main button
Triggers drag-and-drop or export using the currently selected option.
Image Only
Stages only the color image for dragging.
Mask Only
Stages only the mask.
Both
Stages image and mask together; the drag badge confirms two ready files.
Both to WebHelper*
Sends both items directly to WebHelper without drag-and-drop.
i

Floating drag thumbnail: For drag options, clicking the Drag button creates a floating preview under your cursor. Grab and drag from this thumbnail directly into your target web or desktop application. If untouched, the preview automatically dismisses after 5 seconds.

05

ToPS card

Load and place back

Bring in one generated image and choose how Photoshop should insert it.

Load an image

Load File…
Opens a file picker for an image stored on disk.
Paste*
Loads an image from the system clipboard.
Close ×
Clears the loaded image so another result can be loaded.

Place Back

Main button
Places the image using the currently selected mode and active history entry.
Fast & Recommended default
Quickly inserts the image as a standard Smart Object. Best for normal use.
Editable, Slow & Larger File Size
Creates a more editable Smart Object at the cost of time and a larger PSD.
Custom Inpaint Mask
Designed for B&W inpaint masks. Inserts the mask as a hidden Smart Object; Ctrl/Cmd + click its layer thumbnail to reload the selection.
Restore Selection
Restores the original capture selection (or bounds) and feathering back into the active Photoshop document without inserting a new layer.

06

Middle toolbar

Feather Bias controls

Adaptive edge blending and live Photoshop layer mask feathering.

Feather modes

Off default
Disables mask feathering. Inserts the result with a crisp, exact boundary edge.
Outward
Shifts the soft transition outward past the selection boundary to blend smoothly into the surrounding canvas.
Center
Centers the soft feathering transition symmetrically across the selection edge (half inside, half outside).
Inward
Pulls the soft transition inward inside the selection, keeping outer canvas edges crisp and unblended.
i

Adaptive & Non-destructive: The feather radius is automatically computed from the capture padding and selection dimensions so the soft edge never clips at the crop border. It applies to Photoshop's native layer mask Feather property, allowing you to freely fine-tune the slider in Photoshop's Properties panel at any time. Enable this toolbar via Settings… → General Features → Show Feather Bias controls.

07

Global controls

History, status, and settings

These controls affect the whole panel rather than a single card.

Capture history

Each entry follows this pattern:

2: [3:4] (518×690) — Background

  • 2 is the capture number.
  • [3:4] is the closest enabled aspect ratio.
  • (518×690) is the exact pixel size to reuse in an AI tool.
  • Background is the source layer name.

Changing the entry restores that capture's image, mask, coordinates, and layer context.

Panel menu and Settings

Open Photoshop's panel menu with the ≡ icon in the panel header. This native menu is drawn by Photoshop, so it is not visible in the screenshot.

Clear All
Removes all capture history and resets both cards.
Settings…
Opens the settings dialog shown on the right.
Checkboxes
Enable the aspect ratios you want the plugin to recognize.
Up / Down
Change the order in which enabled ratios are evaluated.
Feather Bias
Enables the Feather Bias controls between cards for fine-tuning mask edge expansion and softness.
Helper Token
Manual token entry to pair with Photoshop Helper if automatic pairing fails (shows pairing status).
Save
Stores ratio configuration, feature toggles, and token overrides locally.
!

Status messages: the narrow bar beneath a card reports success, warnings, and errors. If an action does not complete, read this message before retrying.

08

Fast fixes

Troubleshooting

Check these items before repeating a capture or placement.

Capture is empty or contains the wrong pixels

Confirm that a Photoshop document and selection are active. Check PsSource: use Copy merged for the visible composite, or Copy layer for only the active layer.

Soft or transparent edges were lost

Repeat the capture with Slow with transparency, or use Full Doc Mask — Slow when the mask must keep the full document size.

The generated result is stretched

Use the ratio and exact dimensions from the active history entry in the external generator. Prefer exact dimensions when the service allows them.

The result returned to the wrong location

Select the matching capture in the history dropdown before clicking Place Back. The active history entry determines the target coordinates.

Drag-and-drop* is not accepted by the target application

Use Copy Image*/Copy Mask* or Save as PNG instead. Some browser and desktop targets do not accept multiple dragged files.

A Helper action* says the Helper is running but not paired

Photoshop Helper and the plugin pair themselves automatically on startup, so this is uncommon. Close and reopen the panel — pairing also refreshes periodically on its own. If it persists, open the Helper's tray menu, choose Access Tokens → Copy Plugin Pairing Token, and paste it into the plugin's Settings dialog.

*

Why a companion app?

* Requires Photoshop Helper

Photoshop keeps plugins inside a restricted sandbox, so they cannot directly perform some everyday operating-system actions. Photoshop Helper is a small local companion app that handles those tasks and makes the plugin faster and more convenient to use. Controls marked with * need Photoshop Helper running in the system tray.

  • Use the system clipboard Copy Image, Copy Mask, and Paste
  • Drag and drop Start any Drag operation from the panel
  • Export to WebHelper Send the image and mask directly

Works without Helper: anything performed directly inside Photoshop, including Capture and Place Back; panel controls such as history, Clear, and Settings; and saving files (Image Only, Mask Only, and Both) or Load File.

Pairing: the plugin and Photoshop Helper authenticate to each other with a token that Helper generates and delivers automatically — nothing to set up. A manual fallback is available in the plugin's Settings dialog if a Helper action ever reports that pairing failed.
