Configure API Keys & providers.json

This step is optional. You only need to configure these settings if you plan to use the WebHelper (component for AI generation with your own API keys). You can skip this for now and configure it at any time later.
Your settings folder contains a ready-to-fill .env file. Paste your API keys there and save. You can also edit providers.json to customize available models.
Note: You need to restart the application for these changes to take effect.
